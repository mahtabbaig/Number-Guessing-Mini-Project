# 🎯 Number-Guessing-Mini-Project
✨My second Mini Project-Number guessing game✨

- A simple Python game where the computer randomly selects a number and the player tries to guess it.🚀

---
## 💡 How it works
- The computer generates a random number between **1 and 100**.
- The player guesses the number.
- The program tells the player if the guess is **too high** or **too low**.
- The game continues until the player guesses the number correctly.
- Tracks the number of attempts.

## ⚙️ Features
- Random number generation
- Gives feedback:"Too high" or "Too low"
- Counts the number of attempts

## 📚 Concepts Used
- random module
- Loops (while)
- Conditional statement(if-elif-else)
